# StudySync

## Overview

StudySync is a full-stack collaborative learning platform that helps university students connect with tutors or study groups based on course requirements, learning styles, and schedule compatibility. The platform supports real-time messaging, note sharing, and study session scheduling, designed to foster an engaging and productive peer learning environment.

## Deployment Link  
[https://studysync-b.netlify.app/](https://studysync-b.netlify.app/)

## Tech Stack

- **Frontend:** AngularJS, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Real-Time Communication:** WebSockets  
- **Deployment:** Netlify  
- **CI/CD:** GitHub Actions  

## Features

- Smart matching algorithm to connect users based on course, availability, and learning style  
- Real-time chat functionality using WebSockets  
- Session creation and calendar-based scheduling  
- Note and resource sharing within study groups  
- Clean, responsive UI built with Tailwind CSS  
- Modular, component-based frontend architecture for easy scalability
